# 归属判据

- **适用侧**：公共 ｜ **寿命**：常驻 ｜ **最后校准**：2026-11-11

判定顺序固定，前一条不过就不问下一条。任何「这段该放哪」都用这四句，不再新造标准。

1. **换域还成立吗**：把业务域从 ERP 换成别的，这段代码、这条处置是否一字不改？改 → 属域。
   验法：新增行里不得出现业务名词（`grep -rn "订单\|单据\|库存" src/Core`）；既有禁词门禁是 `DomainSwapAc01Tests`。
2. **域自己带一份行不行**：过了第 1 条，再问域自行实现是否同样可行？可行 → 归域或删掉，别塞底座（否则底座膨胀，也违反「底座不单独交付」）。
3. **会不会因为同一个原因一起改**：判定同一方内部的拆与合。会 → 合并；不会 → 分开（例：会话状态按寿命，落库按可回放）。
4. **数值与策略归谁**：底座给尺子（上限、超时、检测机制），域注入刻度（几次算多、哪些可重试）。

做不到第 1 条却放进 Core = 让底座开始理解业务；把第 2 条当成立就上移 = 让底座膨胀。
