# ADR 索引与准入标准

ADR（Architecture Decision Record）只记录**跨模块、且影响后续模块变迁**的架构决策。

## 准入标准（满足其一才写）

- 引入 / 拆分 / 合并 / 移除模块
- 改变模块间依赖方向或分层规则
- 变更跨模块公共契约（Abstractions / Contracts / 事件 / DTO）
- 跨模块的数据所有权、持久化或通信策略
- 影响多模块的框架 / 运行时选型

## 不写（属于实现细节）

- 单模块内部设计、私有类重构
- bug 修复、性能微调
- 依赖补丁版本升级（除非触及公共契约）
- UI / 样式、命名、日志文案

## 模板

```markdown
# ADR-XXXX：<决策标题>

- 状态：提议 / 已采纳 / 已废弃
- 日期：YYYY-MM-DD
- 决策者：<who>

## 背景

## 决策

## 影响

## 备选方案
```
