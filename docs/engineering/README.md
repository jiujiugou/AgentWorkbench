# 文档工程索引

- **适用侧**：公共 ｜ **寿命**：常驻 ｜ **最后校准**：2026-11-22

本目录只放**文档工程自身的元文档**：怎么定义文档类型、怎么判断事实状态、怎么追溯证据、本次改造的结论。具体部件的解释仍在 `docs/core/`，需求与验收仍在各自文件。

| 文件 | 类型 | 解决什么 |
|---|---|---|
| [documentation-policy.md](documentation-policy.md) | Reference / 规范 | 八类文档分类、六种知识状态、架构文档十问、证据追溯规则、维护与生命周期 |
| [研究依据与证据等级.md](研究依据与证据等级.md) | Explanation | 八份外部资料的证据等级、可借鉴处、证据限制（ISO 全文付费、Google 页不可达） |
| [证据追溯索引.md](证据追溯索引.md) | Verification | 六句与工具执行主张的需求→决策→实现→用例→证据链，含 UNKNOWN 清单 |
| [文档改造报告.md](文档改造报告.md) | Verification | 本次改造的盘点结论、已解决/未解决问题、自动化检查输出、需人类决定事项 |

## 配套工具

- `scripts/doc_consistency_check.py`：跨文档同一事实的口径漂移扫描（报告模式，带 `--self-test` 自检）。
- `scripts/check_doc_refs.py`：文档点名的 S 编号与 `.cs` 文件是否还存在（引用漂移）。
- `DocsHygieneTests`（D1–D4）：状态位、相对链接、局部不重定义、纯文本路径存在性。

三者分工不同，不互相替代：引用存在 ≠ 口径一致 ≠ 事实与代码一致。
