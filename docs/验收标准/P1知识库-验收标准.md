# P1 知识库 · 验收标准（可执行版）

> 对应设计：`../设计步骤/P1知识库.md`
> 判定原则：每条给出**可复核证据**（接口返回 / 脚本结果 / 截图），不靠感觉。
> 分工：**A 类自动断言（脚本，确定性，不做 LLM 判断）｜B 类人工抽样（人签字）｜负控必须存在**。

> ⚠️ **现状（2026-10-10）**：仓库中**没有任何验收脚本**（`scripts/` 从未进版本库）。本文件是**标准**（意图与阈值），不是可立即运行的门禁；下文中所有 `scripts/acceptance-p1.ps1` 命令均为**未落地**。手工复核时按第 1–3 节的断言清单用 HTTP 接口逐条核。

## 0. 判定方式说明

| 标记 | 含义 |
| --- | --- |
| **自动** | 由脚本断言给 PASS/FAIL（脚本**未落地**，见顶部说明）；当前需手工用接口核 |
| **半自动** | 脚本给出统计/预筛，人复核确认 |
| **人工** | 必须由人抽样判定并记录证据 |

## 1. 功能验收

| 编号 | 标准 | 判定 | 阈值 / 断言 | 证据 |
| --- | --- | --- | --- | --- |
| H1 | 引擎健康 | **自动** | `/api/knowledge/health` 返回 `provider=local` 且 `capabilities.retrieve=true` | 脚本输出 |
| I1 | 入库即索引 | **自动** | 上传 PDF → `parsed`；`/api/knowledge/documents` 中该文档 `indexed=true` 且 `chunkCount>0` | 脚本输出 |
| I2 | 重建索引 | **自动** | `POST /documents/{id}/index` 返回 202，重建后仍可检索 | 脚本输出 |
| R1 | 检索有命中 | **自动** | `POST /api/knowledge/retrieve` 对有效问题返回 `≥1` 条命中 | 脚本输出 |
| R2 | 命中可溯源 | **自动** | 命中含 `documentId/seq/fusedScore/content`，且 `documentId` 指向真实文档 | 脚本输出 |
| D1 | 删除级联 | **自动** | 删除文档后，知识库列表与检索都不再出现该文档 | 脚本输出 |

## 2. 质量验收

| 编号 | 标准 | 判定 | 阈值 | 证据 |
| --- | --- | --- | --- | --- |
| Q1 | 引用可点击回原文 | **人工** | 问答结果引用可跳转 `文档详情` 对应块并高亮 | 截图 |
| Q2 | 检索调试面板 | **人工** | 面板显示 top-k 片段/来源/两路分数/融合分 | 截图 |
| Q3 | 混合检索有效 | **半自动** | 配好 Embedding 后，向量路有分数（`vectorScore != null`） | 抽样记录 |

> 说明：未配置 Embedding（`Provider=none`）时，向量路自动降级、仅全文检索，`vectorScore` 为 null；这不属于失败，但 Q3 需在配置 bge-m3 后复核。

## 3. 负控（红队）——必须存在，且必须“会失败”

| 编号 | 负控输入 | 判定 | 期望结果 |
| --- | --- | --- | --- |
| N1 | 无关问题（无任何命中） | **自动** | `retrieve` 返回 `0` 条 |
| N2 | 无关问题调用带引用问答 | **自动** | `sources=[]` 且回答为“资料不足…”，**不得编造** |

## 4. 测试集

- 来源：复用 P0 的 `tests/corpus/`（`sample-contract.pdf`，单页、可解析）做入库/检索/删除闭环。

## 5. 自动化脚本

> **未落地**：以下脚本在仓库中不存在（`scripts/` 从未进版本库）。保留命令形态是作为将来补齐门禁时的目标接口。

```powershell
# 默认：构建 → 清库 → 起服务 → 跑全部验收 → 停服务
powershell -ExecutionPolicy Bypass -File scripts/acceptance-p1.ps1

# 服务已在运行（不自动起停）
powershell -ExecutionPolicy Bypass -File scripts/acceptance-p1.ps1 -NoStart

# 指定地址
powershell -ExecutionPolicy Bypass -File scripts/acceptance-p1.ps1 -BaseUrl http://localhost:8080
```

- 断言：H1/I1/I2/R1/R2/D1 + N1/N2。
- 退出码：**全过 0；有失败 1**（可用于 CI 门禁）。
- 输出：每个断言的 PASS/FAIL 与明细。

## 6. 放行判定

- **自动**：H1/I1/I2/R1/R2/D1 + N1/N2 全 PASS。
- **人工**：Q1/Q2 达标 且 Q3 已复核（配置 Embedding 后）。
- 二者同时满足 → **P1 通过**。
- 未达标项记入问题清单，作为后续迭代输入。
