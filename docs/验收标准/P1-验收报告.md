## 3. 实现要点（与设计对照）

| 设计项 | 实现 |
| --- | --- |
| 向量库 | `CommunityToolkit.VectorData.SqliteVec`（sqlite-vec）；集合 `chunks_vec`，键 `chunk_id` |
| 全文检索 | SQLite `FTS5` + `trigram`；`chunks_fts(content, document_id, chunk_id)` |
| 混合检索 | 向量 ∪ FTS → **RRF 融合**；中文短词自动走 `LIKE` 兜底 |
| Embedding | `OllamaSharp`（bge-m3）或 OpenAI 兼容 `/embeddings`；未配置时降级为纯全文 |
| 带引用问答 | `/api/knowledge/ask` 与 SignalR `Ask`；无命中即拒答，不编造 |
| 防腐层 | `IKnowledgeEngine` + `KnowledgeEngineRegistry`；`local` 已实现，其余为不可用 stub |
| 规则库 | `rules` 表 + `/api/knowledge/rules` 管理入口（内容 P2 填充） |
