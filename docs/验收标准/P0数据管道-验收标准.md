# P0 数据管道 · 验收标准（可执行版）

> 对应设计：`../设计步骤/P0数据管道.md`
> 判定原则：每条给出**可复核证据**（接口返回 / 脚本结果 / 截图），不靠感觉。
> 分工：**A 类自动断言（脚本，确定性，不做 LLM 判断）｜B 类人工抽样（人签字）｜负控必须存在**。

## 0. 判定方式说明

| 标记 | 含义 |
| --- | --- |
| **自动** | 由 `scripts/acceptance-p0.ps1` 断言，给 PASS/FAIL |
| **半自动** | 脚本给出统计/预筛，人复核确认 |
| **人工** | 必须由人抽样判定并记录证据 |

## 1. 功能验收

| 编号 | 标准 | 判定 | 阈值 / 断言 | 证据 |
| --- | --- | --- | --- | --- |
| A1 | 上传并流转 | **自动** | 返回 `id`；文本层文档终态 `parsed`；扫描件终态 `failed` | 脚本输出 |
| A2 | 页文本解析 | **自动** | `pages` 条数 == `pageCount` 且 `pageCount > 0` | 脚本输出 |
| A3 | 清洗 | **半自动** | `cleanedText` 非空；人工抽检无正文误删 | 脚本 + 抽样表 |
| A4 | 切分 | **自动** | `chunks` 条数 > 0，且每块含 `pageFrom/pageTo` | 脚本输出 |
| A5 | 重叠 | **人工** | 抽样相邻块，存在约 15% 重叠 | 抽样表 |
| A6 | 状态可恢复 | **自动** | 对文档 `reparse` 后终态回到 `parsed` | 脚本输出 |
| A7 | 删除 | **自动** | `DELETE` 后列表不再包含该 `id` | 脚本输出 |
| A8 | 前端预览 | **人工** | 页面完成"上传→列表→详情（原文/清洗/chunk）" | 截图 |

## 2. 质量验收

| 编号 | 标准 | 判定 | 阈值 | 证据 |
| --- | --- | --- | --- | --- |
| Q1 | 解析质量 | **半自动** | 文本层样本 `pageCount>0` 且总 `cleanedText` 长度 > 0（自动）；人工抽检 **≥80% 页**可读 | 脚本 + 抽样表 |
| Q2 | 切分质量 | **人工** | 抽样 **≥80% 块**边界落在句/条款处 | 抽样表 |
| Q3 | 已知问题清单 | **人工** | 输出清单：页眉页脚残留/表格丢内容/标题误判/跨页条款被切断等，逐条记样例 | 报告 |

## 3. 负控（红队）——必须存在，且必须“会失败”

> 没有负控的验收 = “永远为真”的无效验收。

| 编号 | 负控输入 | 判定 | 期望结果 |
| --- | --- | --- | --- |
| N1 | 扫描件 PDF（无文本层，如 `samr-05`） | **自动** | 终态 `failed` 且 `error` 非空 |
| N2 | 非 PDF 文件（`.txt`） | **自动** | HTTP `400` |
| N3 | 伪造 PDF（`.pdf` 内含乱码） | **自动** | 终态 `failed` |

## 4. 测试集

- 来源：公开**合同示范文本**（市场监管总局合同示范文本库），`tests/corpus/fetch-corpus.ps1` 下载。
- 覆盖：买卖/租赁/服务/旅游等，文本层为主，另含 **1 份扫描件**做负控。
- 存放：`tests/corpus/`（原始 PDF 保留）。

## 5. 自动化脚本

```powershell
# 默认：构建 → 清库 → 起服务 → 跑全部验收 → 停服务
powershell -ExecutionPolicy Bypass -File scripts/acceptance-p0.ps1

# 服务已在运行（不自动起停）
powershell -ExecutionPolicy Bypass -File scripts/acceptance-p0.ps1 -NoStart

# 指定地址
powershell -ExecutionPolicy Bypass -File scripts/acceptance-p0.ps1 -BaseUrl http://localhost:8080
```

- 断言：A1/A2/A4/A6/A7 + Q1(自动部分) + N1/N2/N3。
- 退出码：**全过 0；有失败 1**（可用于 CI 门禁）。
- 输出：每个断言的 PASS/FAIL 与明细。

## 7. 放行判定

- **自动**：A1/A2/A4/A6/A7 + N1/N2/N3 全 PASS。
- **人工**：A3/A5/A8 + Q1/Q2 达标 且 Q3 有产出。
- 二者同时满足 → **P0 通过**。
- 未达标项记入问题清单，作为后续迭代输入。
