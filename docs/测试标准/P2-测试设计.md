# P2 测试设计（双轨试点）

> P2 是 LLM 首次进入主流程、判定型 → 判定+度量的分叉点。
> 关联：`docs/验收标准/P2要素抽取与比对-验收标准.md`、`scripts/acceptance-p2.ps1`、`docs/设计步骤/P2要素抽取与比对.md`。

## 1. 资产盘点（按轨道）

| 组件 | 轨道 |
| --- | --- |
| `RuleBasedElementExtractor`、三个 `IRuleChecker`、`ReviewService` 编排、两个 Registry | 判定型（值/状态/幂等/删除可判） |
| `LlmElementExtractor` 的**解析契约** | 判定型（用 mock/replay） |
| 要素/清单**质量**、无关文档误报 | 度量型（程序计算） |

> LLM 部分拆两半：**契约**用 mock 判定；**质量**用金标程序计算。都不调真模型。

## 2. 不变量（正例绿 · 负控红）

| # | 不变量 | 负控（做坏 → 红） | 现状 |
| --- | --- | --- | --- |
| I1 | 无关/非合同文档不得产生 `high` 且无证据的清单 | 去掉文档相关性门控 → 非合同套用合同规则 → 出现 high | PASS（N1） |
| I2 | 非法 mode（含 `llm`）必须 4xx，或 run failed 且 error 非空 | `Normalize` 默认 `both` → 202 succeeded | PASS（N2） |
| I3 | 有值要素绑定真实 chunk（`chunkId` 非空、`seq` ∈ chunks、`evidence` 非空） | 抽取器返回 null 证据 | PASS（E2） |
| I4 | 清单可溯源或显式 null | 伪造 seq | PASS（C2） |
| I5 | 删文档级联清除 runs/elements/findings | 去掉 FK 级联 | PASS（D1） |
| I6 | 重跑幂等（同 mode 行数不翻倍） | 去掉先删后插 | PASS（RR1） |
| I7 | 未配模型时规则轨仍完成、`llmExtract=false` | 强制依赖 LLM | PASS（降级） |
| I8 | LLM 返回非 JSON → 该步/run failed，且不落脏数据 | 抹掉解析失败处理 | 现状 SKIP → **改为 mock 判定** |

## 3. 验收映射（`acceptance-p2.ps1`）

H1/R0/E1/E2/C1/C2/S1/D1/RR1/N1/N2/N3/N4 = PASS；N5/L1 现 SKIP。

- **N5**：起本地 mock（返回非 JSON）→ 判定型，不再 SKIP。
- **L1**：record-replay 固定 JSON → 判定型，不再 SKIP。

## 4. 修复（红绿对照）

- **I2/N2**：`ReviewService.Normalize` 白名单（`extract|compare|both`），非法抛 `ReviewInvalidModeException`；`ReviewController` catch → 400。
- **I1/N1**：加文档相关性门控（`DocumentRelevance.LooksLikeContract`）——非合同文本跳过规则比对，不产生高危且无证据清单；真实合同缺条款仍按规则给出 high，不影响 C1。
- **I8/N5、L1 去 AI 化**：加本地 mock 端点，验收脚本改为确定性断言。

## 5. 度量层（EVAL-p2，程序计算）

金标 `tests/benchmark/p2/golden/`；负控 `negative/`、`unrelated/`。

| 指标 | 阈值 |
| --- | --- |
| 抽取 F1 | ≥ 0.80 |
| 证据绑定率 | = 100% |
| 误报率（无关文档） | = 0 |
| 非法输入拒绝率 | = 100% |

产出 `scripts/eval-p2.ps1` → `tests/benchmark/p2/report.json`。

## 6. 故障注入（`tests/defects/`）

N2 默认 both / N1 去掉封顶 / E2 null 证据 / RR1 去掉先删 / N4 去掉状态校验 → 期望被判红。**检出率 = 100%** 为门禁（N2 属缺失校验，变异测不到，必须注入）。

## 7. 门禁

`stryker-config.json` `break = 60`；故障注入检出率 100%；`eval-p2.ps1` 指标达标。任一不达标即 P2 不放行。
