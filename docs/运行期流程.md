# 运行期完整流程（主干十步）

- **适用侧**：公共 ｜ **寿命**：现状 ｜ **最后校准**：2026-11-11
- **回答**：一次 run 的主干顺序与失败走向；每一步做什么、留下什么、出错时怎样
- **不回答**：实现细节（模块 README）、当前完成度（测试红绿）、执行计划（`plans/`）

**这份流程是契约坐标，不是任务清单，也不是完成度清单。** 每一步先读**归属**（一行），
再读四栏：`怕什么` → `交给下一格什么` → `不许留下什么` → `不归本格`。
四栏写的是「这一步必须成立的条件」，不是「现在已经做到了什么」——是否满足由测试红绿证明，
本文不维护状态、不列缺口、不排顺序。它存在的意义是给产品侧一个立足点：新问题来了有格子可归。

**「这一步做什么」不写在这里**：那是测试方法名的职责（`S05_01_…`）。同一句写两处就是两份副本，
一处改一处不改就会漂——所以功能只活在方法名里，本文只写「怕什么」和「不许留下什么」。

## 怎么用这份流程

- 每步一个**稳定 key**（`S01`–`S10`）。测试注释、其它文档、讨论一律指 key，不指「第几步」、
  不指章节号、不指代码行号。改一步等于改一个决策，改完只动文件头那一行「最后校准」。
- **归属写在标题下一行**：`Host` / `Core` / `域`。换动作域时逐格看这一项，
  标 `Core` 的步骤，`src/Core` 与 `docs/core/` 的 diff 必须为空
  （AC-01 / [README.md](README.md) §2 的 AC-01-doc）；标 `域` 的才允许变。
- 新发现的问题，先判**它属于哪一步的哪一段**。归得进去 → 补那一段的契约或补实现，
  不单独开新文档；归不进去 → 说明流程本身漏了一步，那才改本文。
- **缺口状态不进本文**：红的测试就是缺口，修好自然转绿。补不了、需要记录过程的，
  进 `docs/plans/` 只追加，不在这里开「连锁问题」小节。
- 文档写法只在 [README.md](README.md) §6 定义一次。各部件职责见 `docs/core/*.md` 部件文档
  （`runtime.md` / `tools.md` 已不在工作区，别再按旧路径找）。
- **三类外部范式怎么用**（只约束用法，不新增装置）：
  - **形状**（propose-then-commit 一类）只在**写或改某一格四栏**时当检查表用：问这一格承诺的句子
    能不能被反驳。它不产生代码、不产生测试；社区里有，不等于本格必须验。
  - **迭代方法**（eval-driven development 一类）只在**出现真实失败**时用来补判据：一条新判据必须来自
    「正本承诺的句子」或「真跑 / 探针暴露的失败」，不得来自「文档里出现了一句话」；补完要能改坏变红。
  - **阶段状态**（`scripts/stage_gate.py`）只在**每次改动后**判定 PASS / BLOCKED，不解释、不列缺口。
  三者顺序固定：定义 → 实现 / 失败 → 判定。**判据一旦定下，不许因为红了就改定义。**

## 主干十步

### S01 · 你输入一句话

**归属**：Host（前端 `ChatView` + `AgentHub` 入口）

- **怕什么**（人写，≤3 条）：① 用户以为发出去了，其实后端没收到；② 同一句话跑了两遍，
  动作被执行两次；③ 一次失败之后，这个连接再也发不出去。
- **交给下一格什么**：一条带本次编号的输入——文本 + 归属会话 + 编号，编号不可缺省。
- **不许留下什么**：空输入 → 不起 run、不建会话、不落消息、不产生终态；
  缺编号 → 只出一条本地错误，不当成这轮失败；任何失败 → 连接必须还能发下一次。
- **不归本格**：前端本地拦截、界面怎么提示、身份与会话校验（S02）；**重放不在本格**——
  开之前必须先做输入级去重（`action_idempotency` 只护动作，不护 run）。
  **但后端不得因此信任前端**：绕过前端直连 Hub 时，「不许留下什么」同样适用。

### S02 · Hub：验身份、取会话

**归属**：Host（`AgentHub`）

- **怕什么**（人写，≤3 条）：① 不该进来的人进来了——未登录、身份取自请求体、续写别人的会话、
  并发请求之间串号；② 一次输入起了两次 run；③ 出错时用户看不出是出错（模型没配置、连接断了）。
- **交给下一格什么**：一个经归属校验的会话（`sessionId` 属于当前主体）+ 主体名 + 覆盖整段 run
  的身份作用域；作用域内三元组恒非空，run 结束后还原。
- **不许留下什么**：入口前拒绝（未登录 / 缺编号 / 同连接已有生成）→ 不探活、不建会话、不落消息、
  不建作用域、不起 run；探活失败 → 探活已发生，此后零副作用；连接中途断开 → 明确终态 `cancelled`，
  已发生的会话、user 消息与轨迹保留。
- **不归本格**：同一会话的互斥（`ISessionRunGate` 在 Harness 两入口，不在 Hub）；
  `requestId` 的派生（S05 自己做）。**身份只取认证声明，不取请求体**——这条同时是 S05 的前提；
  作用域起点必须在会话确定之后（不能用客户端传来的 `conversationId`）。

### S03 · Harness 组上下文

**归属**：Core（`Runtime.Harness` + `Runtime.Context` + `Runtime.Session`）

- **怕什么**（人写，≤3 条）：① 同一会话同时跑两个 run，两边的历史互相覆盖；② 模型拿到的上下文是错的
  ——历史漏了、指令没注入、工具清单不对；③ 模型不可用时用户看到的是「生成中」，事后也查不到轨迹。
- **交给下一格什么**：一次模型调用所需的完整输入——历史 + 指令 + 工具白名单 + 能力清单；
  同一 `sessionId` 同时只有一个 run。
- **不许留下什么**：同一会话的第二个 run 不得发起模型调用——**两个入口都要拦，只拦一个等于没拦**；
  互斥键是 `sessionId`，不是连接；模型不可用 → 明确终态、轨迹照落。
- **不归本格**：模型输出的解析与工具调度（S04）；探活（S02）；上下文内容的业务正确性
  （知识库与记忆各自负责）。

### S04 · 模型决策

**归属**：Core（`Runtime.Tools` 工具环）+ 组合根（模型端点）

- **怕什么**（人写，≤3 条）：① 模型调了白名单之外的工具（越权碰外部系统）；② 模型用纯文本冒充
  「已经做了」，实际一次工具都没调（谎报执行）；③ 模型既不给文本也不给工具调用，用户看到空白。
- **交给下一格什么**：一个落在白名单内的工具调用，或一段纯文本（后者直接去 S10）。
- **不许留下什么**：白名单外的工具不出现在模型的工具清单里（`ToolCatalog` 按策略过滤）；
  模型输出只被解析成这两种之一，中间不丢不添；**两者都没有（既无文本也无工具调用）时，
  不得当成本轮成功**。本步没有独立拒绝路径，进入本步后的失败由 Harness 收口并落轨迹（S03 / S09）。
- **不归本格**：工具的执行、审批与幂等（S05–S08）；迭代上限与重复调用检测（S09）。
  **「说了但没做」的处置不在本格**——本格只能保证「没调工具就没有动作」，
  界面怎么如实显示「本轮执行了 0 个动作」归 S10。

### S05 · `propose_action` 填成一张单子

**归属**：Core（`Tools.Builtin`）+ Host（提供输入身份）

- **怕什么**（人写，≤3 条）：① 请求号不稳定或不唯一——同一句话重放会变成两张单；② 参数不是
  合法 JSON 对象，或底座试图理解参数——网关拿到脏数据 / 底座开始懂 ERP；③ 主体取自请求体
  而不是身份作用域——越权执行。
- **交给下一格什么**：一个 `subject` 与 `requestId` 都齐全的 `ActionRequest`；参数对底座不透明。
- **不许留下什么**：无身份 / 非法 JSON → `rejected`，**不进网关**，零外部调用。
- **不归本格**：四道闸门的判定（S06）；`requestId` 的具体算法——只要求稳定，且能由
  「主体 + 会话 + 编号 + 动作」重新算出来。

### S06 · 四道闸门

**归属**：Core（`ActionGateway`）；规则与权限的**内容**由域注入

- **怕什么**（人写，≤3 条）：① 判定顺序被换（先业务规则后权限）→ 越权放行；② 某道判定没有
  落痕 → 事后说不清依据；③ 审计写失败仍放行 → 动作无据可查。
- **交给下一格什么**：判定通过、且**每道判定都成功落痕**的请求。
- **不许留下什么**：任一道 deny → `Rejected`（HTTP 422），**executor 零调用**；审计写失败同样拒绝。
- **不归本格**：规则与权限的具体内容（域）；`RiskLevel` 不参与决策；是否需要审批（S07）。

### S07 · 审批：挂起 or 直接放行

**归属**：Core（`ActionRunService`）；是否需要审批由域的 `ActionSpec` 决定

- **怕什么**（人写，≤3 条）：① 该审批的没审批就执行；② 审批过了但请求已被改动（参数变了、
  审批还生效）；③ 审批卡住不返回，用户永远等。
- **交给下一格什么**：可执行的请求快照 + 审批当时的判定。
- **不许留下什么**：人工拒绝 → 明确终态且零外部调用；审批超时 → 终态或保持挂起，**不默认放行**。
- **不归本格**：执行本身（S08）。审批与请求快照的绑定强度（参数或策略一变，审批是否失效、
  commit 时怎么校验）还没有判定，现在按「快照」处理。

### S08 · 执行：幂等 → 连接器 → 外部

**归属**：Core 编排；连接器由**域**实现

- **怕什么**（人写，≤3 条）：① 重试导致重复下单；② 超时被当成失败去重放 → 两张单；
  ③ 执行成功但结果没写回 → 模型和用户都不知道。
- **交给下一格什么**：一个确定的终态结果（含外部单号），供模型回传与审计回放。
- **不许留下什么**：超时 / 状态未知 / 重复 → **只查证，不重放**；已有结果直接回放。
- **不归本格**：结果的措辞与展示（S09 / S10）；补偿动作——还没有，正本 §4.1 只要求「办错了能追回」
  的证据链，不等于已实现回滚。

### S09 · 结果回传模型

**归属**：Core（`Runtime.Loop` + `Runtime.Tools`）

- **怕什么**（人写，≤3 条）：① 模型反复调同一个工具，烧时间烧钱；② 迭代超限没收口，
  用户一直转；③ 工具失败被模型当成成功。
- **交给下一格什么**：模型的最终文本答复，或一个明确终态。
- **不许留下什么**：迭代超限 / 重复调用 / 预算耗尽 → 强制收口，状态带归类码。
- **不归本格**：模型说了什么（S04 的问题域）；落库（S10）。

### S10 · 流式输出 + 落库

**归属**：Host（增量推前端）+ Core（落模型历史 / 轨迹 / 动作审计）

- **怕什么**（人写，≤3 条）：① 审计写失败但界面显示成功；② 流式输出中途断了，前端以为完成；
  ③ 三笔落库对不上（对话里有、轨迹里没有）。
- **交给下一格什么**：一次可回放的 run——终态 + 归类码 + 轨迹。
- **不许留下什么**：审计写失败 → **不算成功**，fail-closed。**本轮的动作用量必须如实可见**：
  没有执行任何动作时，界面要能显示「0 个动作」——这是 S04 那条「谎报」的落点。
- **不归本格**：动作本身的正确性（S05–S08）。

## 跨步约束

主干十步能跑，出问题的一直是**交接处**。两条不专属任何一步、但每一步都要守的：

- **身份贯穿**：`clientMessageId`（S01 生成）→ `sessionId` + `subject`（S02 确定）→ `requestId`
  （S05 派生）→ 幂等键（S08 领取）。任何一步把身份做成可缺省，下游判重就失效。
- **零调用优先于办成**：S05 / S06 / S07 的拒绝路径都必须保持「外部系统什么都没发生」，
  这与 S08 的「只查证不重放」是同一条承诺的两端。

## 怎么验 · 阶段状态

**状态只由测试产出**：每一格一个稳定 key、一组测试，按 key 隔离运行。十格同一条命令，只换 `Sxx`：

```
python scripts/stage_gate.py S01
```

- **PASS**：这一组有判据、全绿、且**没有未执行**，退出码 0 → 可以进入下一格。
- **BLOCKED**：有任意一条红、有任意一条未执行（`Skip` 的用例）、或这一格还没有测试组，
  退出码非 0 → 停在这一格；输出会点名是红的还是未执行的。
  **未执行 ≠ 通过**：一条 `Skip` 表示「这一步没有装置守着」，把它算成绿就是让没有保障
  伪装成有保障。
- **按 key 隔离**：全量跑里其它模块的红不计入本格状态；**filter 内不设「预期红」**，
  红了就是没过，没有例外，也不靠人判断。零条判据同样算 BLOCKED，不算通过。
- **判据与哨兵分开**：名字带 `Sentinel` 的用例只提醒「改了要同步文档」，由 filter 排除，
  不计入本格判据条数；它绿不代表契约成立，红也不阻塞。
- 状态不写进本文、不手写、不由文档维护。本文只定义这条规则，不列测试名、用例号与行号
  （它们会漂），也不开缺口清单：红的测试就是缺口，不在本文维护状态位。

文档自身由 `DocsHygieneTests` 守（状态位、相对链接、不重定义写法），改完跑一次。
