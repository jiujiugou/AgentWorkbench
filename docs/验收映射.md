# 六句 · 外部观察点

- **适用侧**：公共 ｜ **寿命**：现状 ｜ **最后校准**：2026-11-21

判定权在外部系统，不在这张纸里。这里只回答四件事：**查哪里、什么算过、什么算失败、现在有没有证据。**
外部不肯开口，就没有验过——六句里任何一句都不能用我们的绿灯顶替。

规格来自 `docs/产品目标与范围.md` §3，这里只做提取，不新写、不解释。

## 1. 真实 API 查状态

- **查哪里**：被接入系统自己的记录，按业务键读回（当前载体 ERPNext：采购单 `name` → `docstatus` / `status` / `supplier` / `grand_total`）
- **算过**：状态码与状态值是对方 API 自己返回的；查不到时系统明确说查不到
- **算失败**：返回的是 mock、假件、或我们自己格式的时间串
- **现在**：**有最小实证（2026-11-20）**。`POST /api/actions` → `erp.query` → `McpActionExecutor` → `frappe_get_doc`，HTTP 200 / `status=succeeded` / `code=mcp_ok` / `externalId=PUR-ORD-2026-00001`，返回真单据全字段。边界：只读，且走 HTTP 入口——模型聊天入口未验（当时 `glm-4-flash` 把 tool call 写成文本，`tools=0`，未进闸）。11-08 Gitea 的 PATCH 201 / DELETE 204 / RFC3339+Z 仍是探针事实，不是完整 run。

## 2. 未审批零外部调用

- **查哪里**：对方系统的记录数 / 访问日志——不是我们自己的调用计数
- **算过**：未点同意时对方记录数不变；拒绝与超时过期都不执行
- **算失败**：审批没点，对方那边多了一条
- **现在**：无证据。写动作 `erp.submit` 的审批门是桩（`Approved=true`、审批人硬编码），没有「真人拒绝」这个状态可验；建单能力（`erp.draft` 的 MCP 绑定）也没做，写动作没有作用对象。S07 拒批后未 Resume 的缺口仍挂着。

## 3. 同 request_id 只有一条

- **查哪里**：对方系统按业务键查到的记录条数（ERPNext 为 `name`，Gitea 为 issue number）
- **算过**：只有一条，第二次返回首次结果
- **算失败**：两条以上——11-08 实测 Gitea 完全忽略 `Idempotency-Key`，同 payload 连发三次得三张单
- **现在**：无证据。11-20 只读链路未触发写动作，没有「连打两次」的对象；Gitea 侧按业务键的读取口仍缺失。只验过我们自己说「没重放」，那不是对方的话。

## 4. 超时只查证不重放

- **查哪里**：超时之后，对方侧有没有第二次写
- **算过**：记「执行中」、发起状态查询、不重放；查不到转人工
- **算失败**：对方侧出现第二次写
- **现在**：无证据。超时归 Unknown 有单测，但「只查证不重放 + 按业务键查证」的外部闭环没跑过。

## 5. 审计五字段

- **查哪里**：任取一笔执行，五字段（意图 / 参数 / 审批人 / 结果 / 外部单号）是否齐全，且「在对方系统里变成什么」能回对方核对
- **算过**：字段齐全，最后一项与对方记录一致
- **算失败**：缺字段，或「变成什么」对不上
- **现在**：**只读路径有实证，写动作后未验**。11-20 那次 `request_id=f4e7faf9858fe41608ddf9b74bd42d03` 的五条阶段轨迹（schema / permission / business_rule / audit / execute）齐全，execute 带 `externalId=PUR-ORD-2026-00001`；但只读没有状态变化可核，「变成什么」要在写动作后才有意义。判定权在对方系统。

## 6. 换第二个体系，底座 diff 为空

- **查哪里**：`git diff src/Core/`，以及第二个体系自己的记录
- **算过**：第二体系跑通同一套运行时，底座 diff 为空，且对方一行没改
- **算失败**：底座出现业务名词 / 引用方向变了，或改了对方
- **现在**：无证据。没有第二载体，第六句一直是空的——它是「任何」这个词的唯一证据。

---

**为什么这里只有六句**：结构层的判据就是 `dotnet test`，元层的判据就是变异器——它们自己会红，是可执行的东西，不需要一张纸复述。
把它们抄进文档，等于把活的判据做成死的陈列。这张纸只放没有现成执行器的那一层。
