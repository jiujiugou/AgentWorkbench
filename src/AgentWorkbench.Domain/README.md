# AgentWorkbench.Domain

纯领域模块，只依赖 Shared，不得引用任何基础设施/实现模块（架构测试强制）。

## 功能

承载与基础设施无关的领域模型：

| 文件 | 说明 |
| --- | --- |
| `Records.cs` | `文档状态机`、`规则库条目`（标准条款 / 风险清单，P1 仅管理入口，内容 P2 填充）、`模型供应商`（OpenAI 兼容端点，Key 明文存储 P2 再加密）、`供应商下的可选模型`（`is_default` 表示当前使用模型） |
| `ChatTurn.cs` | 一轮对话，用于回放历史 / RAG 上下文 |

## 依赖

Shared。
